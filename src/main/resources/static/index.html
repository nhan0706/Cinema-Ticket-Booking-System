Khái Niệm & Minh Chứng HATEOAS (Hypermedia As The Engine Of Application State)

HATEOAS là cấp độ cao nhất (Level 3) trong mô hình trưởng thành Richardson Maturity Model của REST API. Khi client yêu cầu thông tin một bộ phim (ví dụ: GET /api/movies/1), server không chỉ trả về dữ liệu phim mà còn kèm theo thuộc tính _links chứa các URI hành động tiếp theo mà client có thể thực hiện (self, all-movies, update, delete).

Code Triển Khai Trong Controller:

// Trả về EntityModel kèm liên kết động:
EntityModel<Movie> resource = EntityModel.of(movie,
    linkTo(methodOn(MovieController.class).getMovieById(id)).withSelfRel(),
    linkTo(methodOn(MovieController.class).getAllMovies()).withRel("all-movies"),
    linkTo(methodOn(MovieController.class).updateMovie(id, movie)).withRel("update"),
    linkTo(methodOn(MovieController.class).deleteMovie(id)).withRel("delete")
);
return ResponseEntity.ok(resource);

Kết Quả Phản Hồi JSON Thật:

{
  "id": 1,
  "title": "Mai",
  "genre": "Tinh cam / Tam ly",
  "duration": 131,
  "price": 100000.0,
  "_links": {
    "self": { "href": "http://localhost:8080/api/movies/1" },
    "all-movies": { "href": "http://localhost:8080/api/movies" },
    "update": { "href": "http://localhost:8080/api/movies/1" },
    "delete": { "href": "http://localhost:8080/api/movies/1" }
  }
}

🏛️ Danh Sách Bảng & Mô Hình Kế Thừa (Hệ Thống 7 Thực Thể)

Đề tài nhóm: Hệ Thống Quản Lý Rạp Chiếu Phim (Cinema Management System). Áp dụng kế thừa đối tượng User cho Customer và Admin.

1. User (Lớp cha) BASE CLASS

Thuộc tính:

  • id: int (Khóa chính)
  • name: String (Họ tên)
  • email: String (Email)
  • phone: String (Số điện thoại)
  • password: String (Mật khẩu)
2. Customer (Khách hàng) extends User

Kế thừa toàn bộ User, mở rộng thêm:

  • loyaltyPoints: int (Điểm tích lũy thành viên)
3. Admin (Quản trị viên) extends User

Kế thừa toàn bộ User, mở rộng thêm:

  • role: String (SUPER_ADMIN, MANAGER, STAFF)
  • department: String (Bộ phận làm việc)
4. Movie (Thực thể chính CRUD) CRUD & HATEOAS

Thuộc tính:

  • id: int (Mã phim)
  • title: String (Tên phim)
  • genre: String (Thể loại phim)
  • duration: int (Thời lượng tính theo phút)
  • price: double (Giá vé tiêu chuẩn)
5. CinemaRoom (Phòng chiếu)

Thuộc tính:

  • id: int (Mã phòng)
  • roomName: String (Tên phòng)
  • totalSeats: int (Số lượng ghế)
  • screenType: String (2D, 3D, IMAX)
6. Showtime (Suất chiếu)

Thuộc tính:

  • id: int (Mã suất chiếu)
  • movieId: int (Khóa ngoại trỏ Movie)
  • roomId: int (Khóa ngoại trỏ CinemaRoom)
  • startTime: String (Giờ chiếu)
7. Ticket (Vé xem phim)

Thuộc tính:

  • id: int (Mã vé)
  • showtimeId: int (Khóa ngoại Showtime)
  • customerId: int (Khóa ngoại Customer)
  • seatNumber: String (Số ghế)
  • totalPrice: double (Tổng tiền)
